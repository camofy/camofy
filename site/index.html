A FEW ANSWERS

你可能想知道。

Camofy 提供代理节点吗？+

不提供。Camofy 是配置管理与分发工具，你需要自行准备上游订阅或代理节点，并遵守适用的法律及服务条款。

“身份”和 Profile 有什么区别？+

Profile 是可复用的配置模块。身份按指定顺序组合多个订阅和配置 Profile，每个关联可以单独启用或禁用。身份提供订阅链接，也可以关联设备。

更改配置后，设备会立即更新吗？+

云端重新生成身份配置后，绑定的 Agent 通过实时通知获取更新，并在连接失败时以五分钟轮询兜底。Clash Verge Rev、Shadowrocket 等客户端则在刷新订阅后获取新配置，具体频率取决于客户端设置。

已有订阅链接还能继续使用吗？+

可以。云平台的管理入口是 cloud.camofy.app，订阅、安装脚本和下载地址继续由简短的 camofy.app 提供。
