# 本地设计预览

本轮只改官网与云端界面，不改变 API、订阅格式或部署入口。
原始花叶 logo 已保存在 `site/site-assets/logo.png`，导航图标只裁去四周留白。
云端使用同一份本地图案，不请求外部图片服务。

## 启动

在仓库根目录运行：

```sh
node site/preview.mjs
```

另开终端：

```sh
cd web
bun install --frozen-lockfile
bun run dev --host 127.0.0.1 --port 18742 --strictPort --mode design
```

- 官网：`http://127.0.0.1:18741/`。本地服务器把云平台按钮指向本地后台，不改变生产 HTML 的正式地址。
- 后台：`http://127.0.0.1:18742/identities`。默认进入演示账号，所有数据均为虚构。
- 支持查看身份、订阅、Profile、设备详情，搜索、编辑保存、切换关联和模拟内核启停。
- 退出登录后可查看登录/注册设计。用任意格式正确的演示邮箱和至少 12 位密码即可进入；请勿输入真实凭据。
- 不模拟的操作明确报错，不会转发线上。重启开发服务器即可重置演示资源。
- 此模式仅用于界面评审，不代表真实订阅合并、授权或设备控制的端到端验证。

只有显式使用 `--mode design` 的 Vite 开发服务器才加载演示接口；它关闭了后端代理。
正式构建不包含演示数据、预览条或本地服务地址。

## 视觉约定

- 白色侧栏、近白页面、灰黑文字；不再用整块深绿承载导航。
- 绿叶 `#b7c1a9` 只用于用量条等少量提示；花朵 `#f1ded0` 用于小头像。
- 主按钮使用炭灰，错误仍保留红色，成功状态保留小面积绿色。
- 官网删减为首屏、产品示意、三项能力、开源/安装入口，不堆叠解释。
- 身份首页用实际统计替代宣传横幅，详情继续共享 Panel、ConfigPreview 和 URL 标签页。
