# 本地设计预览

本轮只改官网与云端界面，不改变 API、订阅格式或部署入口。
原始花叶 logo 保留在 `site/site-assets/logo.png`；导航与 favicon 使用据此简化的矢量花叶标记
`site/site-assets/mark.svg`（云端副本：`web/src/assets/mark.svg`），不请求外部图片服务。

## 启动

在仓库根目录运行：

```sh
node site/preview.mjs
```

另开终端：

```sh
cd web
bun install --frozen-lockfile
bun run dev --host 127.0.0.1 --port 18742 --strictPort --mode design
```

- 官网：`http://127.0.0.1:18741/`。本地服务器把云平台按钮指向本地后台，不改变生产 HTML 的正式地址。
- 后台：`http://127.0.0.1:18742/identities`。默认进入演示账号，所有数据均为虚构。
- 支持查看身份、订阅、Profile、设备详情，搜索、编辑保存、切换关联和模拟内核启停。
- 退出登录后可查看登录/注册设计。用任意格式正确的演示邮箱和至少 12 位密码即可进入；请勿输入真实凭据。
- 不模拟的操作明确报错，不会转发线上。重启开发服务器即可重置演示资源。
- 此模式仅用于界面评审，不代表真实订阅合并、授权或设备控制的端到端验证。

只有显式使用 `--mode design` 的 Vite 开发服务器才加载演示接口；它关闭了后端代理。
正式构建不包含演示数据、预览条或本地服务地址。

## 视觉约定

- 暖白画布、发丝线分隔、单一叶绿强调色 `#4f6b52`；花瓣粉 `#f6e6df` 只用于头像与标记。
- 主按钮为墨色 `#1d1d1b`，错误红、提醒黄只在需要时小面积出现；卡片悬停不位移、不加阴影。
- 标题不再使用英文小标（eyebrow），列表去掉装饰性图标方块，说明文字收进浅色侧注。
- 官网：首屏、产品示意、三步工作方式、能力列表、开源安装、结尾行动，全部为静态 HTML/CSS，符合 CSP。
- 后台：设计令牌集中在 `web/src/cloud.css` 顶部，`store.css`、`proxy-control.css`、`assistant.css` 只引用令牌。
