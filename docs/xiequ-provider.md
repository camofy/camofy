# 携趣短效代理

在云端「拉取代理」中选择「携趣 · 短效代理」，填写携趣控制台生成的
`api.xiequ.cn/VAD/GetIp.aspx` 完整提取 URL（`act=get`、`num=1`）、白名单 `uid/ukey`。
提取 URL 的 uid 必须与白名单账号一致。支持 JSON 或单行 `IP:port`，协议选择要与套餐一致。
HTTP/HTTPS 代理使用 HTTP CONNECT；SOCKS5 套餐可选 SOCKS5。

点击「预览服务器公网 IPv4」，确认显示的 IP 后保存。预览来自云端进程直连的
两个 HTTPS IPv4 查询服务，不使用浏览器 IP、Cloudflare IP、Forwarded 头或域名 A 记录。
预览凭证经认证加密、绑定租户、5 分钟过期；保存时再次核对出口。
只向 HTTPS 白名单管理接口添加这一条，再查询确认存在，绝不删除既有条目。
服务器出口改变时重新预览确认；多出口部署应先保证稳定出口，不能自动授权未知 IP。

每个订阅 Profile 选择此代理即可。手动与定时刷新使用相同队列：每次调用提取接口
获取一个新 IP，立即通过该代理请求 YAML，不缓存短效 IP、不自动重试供应商收费请求、
不直连降级。失败保留上次有效内容。供应商原始消息及带密钥 URL 不写入错误日志。
每个携趣 uid 跨实例共享提取限速，最多每秒窗口 5 次，排队上限约 4 秒。
刷新卡片显示本次提取的代理端点及时间，方便诊断，绝不显示 API 密钥。

所有凭据按现有资源模型加密入库，API 不回显密钥或完整提取 URL；编辑留空保留。
只接受官方短效提取域名/路径；DNS 固定、禁用重定向、公共地址检查和响应大小限制
同时用于供应商请求，订阅代理仍使用数字目标地址以防远程 DNS 绕过 SSRF 防护。
携趣提取域名对海外解析可能返回回环地址；这时仅针对该固定域名使用 Google HTTPS DNS
的国内区域解析视图，校验问题域名、CNAME 链与所有最终 A 记录均为公网地址后固定连接。
不向 DNS 服务发送 API 密钥，不修改全局 DNS，不硬编码 CDN IP。
白名单及提取请求强制 IPv4，与预览一致。若提取接口只支持 HTTP，密钥会明文传输，
界面明确提示；不能用关闭 TLS 校验来替代 HTTPS 支持。

运维批量配置：凭据 JSON 存在私有部署仓库，不放入 Camofy 源码仓库。
在本地运行 `scripts/configure-xiequ.ps1 -ConfigFile <private.json> -ExpectedIP <confirmed-ip>`，
脚本通过现有运维 SSH 权限为指定云端账号临时创建会话，确认出口、创建/更新代理，
再将该账号所有订阅绑定此代理并刷新，最后清理临时会话。
原有刷新间隔与自动刷新开关不变，独立 Profile、身份与路由器设置不变。
