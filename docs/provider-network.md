# 代理厂商网络请求

`src/cloud/provider_net.rs` 是代理厂商提取接口共用的网络层；
`src/cloud/provider_net/dns.rs` 负责受控 DNS 查询。
它们不更改服务器全局 DNS，也不替换用户订阅下载的 DNS / SSRF 策略。

## 厂商适配与公共算法

厂商适配器负责四件事：

1. 校验接口域名、路径、协议、参数和凭据；
2. 声明 DNS 策略；
3. 在每次提取前执行厂商限流准入；
4. 解析业务响应，校验返回的代理地址。

公共层不包含携趣域名、uid、vkey、白名单或响应字段规则。
适配器通过 `provider_net::get_text(url, Some(policy), private)` 复用公共解析和传输。
`DnsPolicy::default()` 明确关闭 ECS；需要地区调度的厂商单独声明网段。
携趣在自己的适配器中配置 `223.5.5.0/24`，不会成为其他厂商的默认值。
`None` 保留系统解析，仅用于不需要受控 DoH 的接口和本地测试。

当前供应商只返回 IPv4 代理，公共厂商解析也只查询 A 记录。
新增 IPv6 供应商时应显式扩展地址族策略及其测试，不能默默跳过现有校验。

## 解析算法

- 缓存未命中时并行查询固定的 Google 与阿里 DoH 服务，使用标准 DNS wire format；
  报文由 Hickory 编解码，不自行实现 DNS 压缩指针等协议细节。
- 首个**通过全部校验**的回答胜出，而不是首个 HTTP 200 或首个 DNS 回答；
  一路返回回环地址、内网地址、无效回答或失败时，继续等待另一路。
- 校验事务 ID、问题、类型、响应标志、截断标志及 CNAME 链；只接受查询链上的公网 IPv4。
  无关 additional / answer 记录不能成为连接目标；混有非公网目标的回答整体拒绝。
- 两路都失败或整个查询超过 4 秒即结束，包括等待同一域名的在途查询。
  不回退到未经校验的地址，不硬编码厂商 CDN IP。
- 成功记录按域名和 ECS 策略隔离缓存，取 A 记录及 CNAME 链上的最短 TTL，最长 300 秒。
  TTL 为 0 的结果不复用，过期结果不兜底使用；上限 128 个缓存键。
- 同一键的并发缓存未命中会合并；查询取消会释放锁，不遗留永久在途状态。
- DNS 请求只携带厂商域名和所声明的网段，不携带提取 URL 的路径、查询参数或凭据。

## 提取与重试

DNS 查询可以并行，但一次 `get_text` 只发送一次携带凭据的厂商 API 请求。
实际连接固定到校验过的 IP，保留原始 Host / TLS SNI，禁用重定向和环境代理。
接口请求最多 12 秒，连接最多 4 秒，响应最多 64 KiB。
连接失败或接口超时时淘汰该 DNS 缓存键，让下一次有界重试重新解析。

刷新任务统一最多 3 次尝试，继续使用原有退避、Retry-After、限流、总时限和配置版本检查。
普通订阅的重试语义保持不变。启用 Zyte 的 WestData 刷新只允许在 `proxy` 准备阶段重试；
进入面板会话后不通过外层重试重复登录、验证码或激活。面板自身的验证码重试保持不变。
准备阶段失败不会触发直连降级。厂商明确拒绝、无效响应和永久 HTTP 错误不会盲目重试。

白名单添加等可能有写入副作用的接口仍使用原有路径，本改造不对其新增自动重试。

## 安全诊断

以下错误码能区分获取代理阶段的故障；均配固定中文提示，不包含厂商账号或接口 URL：

| 错误码 | 含义 |
| --- | --- |
| `proxy_dns_timeout` | DNS 查询或等待在途查询超时 |
| `proxy_dns_failure` | DNS 服务或连接暂不可用 |
| `proxy_dns_invalid` | 回答无效或未提供安全公网地址 |
| `proxy_extract_connect` | 无法连接提取接口 |
| `proxy_extract_timeout` | 提取请求超过时限 |
| `proxy_extract_http` | 提取接口返回 HTTP 错误，附数字状态码 |
| `proxy_extract_response` | 响应超限、格式错误或未返回可用代理 |
| `proxy_configuration` | 请求配置无效 |

默认 info/warn 日志把任务 claim 和尝试次数关联到同一个 `subscription_refresh_attempt` span。
每次受控 DNS 查询记录缓存命中/未命中、网段、解析服务、选中的公网 IP 与 TTL；
提取阶段记录域名、端口、完整候选 IP:端口集合、阶段、耗时、HTTP 状态、
`reqwest` 的连接/超时/响应体标志、底层 I/O 错误类别和操作系统错误码。
如果解析返回多个 IP，候选集合不能单独证明哪个 IP 首先连接失败。
DNS 缓存失效和请求完成也会留痕。日志不输出含 uid/vkey 的完整 URL、
请求或响应正文；用户可据 IP/端口和 errno 判别携趣节点不可达、路由错误或超时。
下载订阅本身的 403 不归类为代理提取失败；解析成功也不代表下载站一定接受该代理出口。

## 本地验证

`cargo test --locked --bin camofy-cloud provider_net` 使用本地 DNS / HTTP 替身，
覆盖竞速、校验、TTL、策略隔离、并发合并、取消、缓存上限、超时、重定向、响应限制、
Retry-After 和错误脱敏；不会提取真实付费代理或操作 WestData 账号。

需要核对当前网络与真实 DoH 的兼容性时，显式运行：
`cargo test --locked --bin camofy-cloud public_doh_with_and_without_regional_policy -- --ignored --nocapture`。
该冒烟测试分别探测两家解析服务，只查询公开域名，覆盖默认策略及携趣国内策略，
输出解析服务、域名、耗时和安全错误码，不访问代理提取接口。

如果本机代理把 DoH 服务域名解析为 `198.18.0.0/15` 等 Fake-IP，冒烟测试会被公网地址校验
拒绝。这是安全边界生效，不应放宽校验；请在使用真实公网解析的网络中验证。
