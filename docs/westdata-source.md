# Account-based subscription sources

The supported provider can require login and a temporary subscription activation
before a refresh. Configure credentials through the authenticated cloud interface.
Select the intended product after discovery and use the configured fetch proxy.
A failed login, activation or download retains the previous valid configuration.

Credentials and full subscription URLs belong in encrypted storage. Public
errors must not include cookies, passwords, API keys or subscription tokens.
Respect provider challenges and authentication requirements. Keep actual account,
network, provider-response and deployment records outside the public repository.
